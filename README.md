# Python ATM Menu Practice

Two console exercises modelling an ATM-style menu with a starting balance of 10,000.

## ✨ Highlights

- Display balance, calculate a withdrawal, or calculate a deposit.
- Practise loops, numeric input, and menu choices.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "new.py"
```

Follow the prompts in the terminal.

## 🗂️ Repository guide

- [new.py](new.py)
- [while.py](while.py)

## 📝 Project notes

This is a calculation demo, not a banking application. Deposits and withdrawals are printed but are not assigned back to the stored balance. There is no authentication or persistence.
